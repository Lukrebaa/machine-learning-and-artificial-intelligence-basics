# Machine Learning and Artificial Intelligence Basics

This repository contains implementations of fundamental machine learning and artificial intelligence algorithms in both MATLAB and Python. The implementations focus on core algorithms and techniques that form the building blocks of modern AI systems.

## Repository Structure

### Code
The code is organized by programming language:

#### MATLAB Implementations
- **BFS.m**: Breadth-First Search algorithm implementation
- **DFS.m**: Depth-First Search algorithm implementation
- **hill_climbing.m**: Hill Climbing optimization algorithm
- **main.asv**: MATLAB autosave file for main script
- **main.m**: Main MATLAB script for running experiments
- **read_tsp_file.m**: Utility to read TSP (Traveling Salesman Problem) file format
- **simulated_annealing.m**: Simulated Annealing optimization algorithm
- **visualize_path.m**: Visualization tool for pathfinding results

#### Python Implementations
- **BFS.ipynb**: Breadth-First Search algorithm notebook
- **decision_tree.ipynb**: Decision Tree classifier implementation
- **decision_tree0.ipynb**: Initial version of decision tree implementation
- **decision_tree1.ipynb**: Enhanced version of decision tree implementation
- **DFS.ipynb**: Depth-First Search algorithm notebook
- **HC.ipynb**: Hill Climbing algorithm notebook
- **knn0.ipynb**: Initial K-Nearest Neighbors implementation
- **knn1.ipynb**: Enhanced K-Nearest Neighbors implementation
- **linear_regression0.ipynb**: Basic linear regression implementation
- **linear_regression1.ipynb**: Advanced linear regression implementation
- **logistic_regression0.ipynb**: Basic logistic regression implementation
- **logistic_regression1.ipynb**: Advanced logistic regression implementation
- **lsvm0.ipynb**: Initial Linear Support Vector Machine implementation
- **lsvm1.ipynb**: Enhanced Linear Support Vector Machine implementation
- **SA.ipynb**: Simulated Annealing algorithm notebook

## Algorithms Implemented

### Search Algorithms
- **Breadth-First Search (BFS)**: Explores all neighbor nodes at the present depth before moving to nodes at the next depth level
- **Depth-First Search (DFS)**: Explores as far as possible along each branch before backtracking

### Optimization Algorithms
- **Hill Climbing**: A local search algorithm that continuously moves in the direction of increasing elevation/value
- **Simulated Annealing**: A probabilistic technique for approximating the global optimum of a given function

### Machine Learning Algorithms
- **Decision Trees**: A non-parametric supervised learning method used for classification and regression
- **K-Nearest Neighbors (KNN)**: A non-parametric method used for classification and regression
- **Linear Regression**: A linear approach to modeling the relationship between a dependent variable and one or more independent variables
- **Logistic Regression**: A statistical model that uses a logistic function to model a binary dependent variable
- **Support Vector Machines (SVM)**: Supervised learning models used for classification and regression analysis

## Usage

### MATLAB
To run the MATLAB implementations:
1. Open MATLAB
2. Navigate to the code/matlab directory
3. Run the main.m script or individual algorithm files

### Python
To run the Python implementations:
1. Ensure you have Jupyter Notebook installed
2. Navigate to the code/python directory
3. Open and run the desired .ipynb files

## Applications

The repository demonstrates the application of these algorithms on various problems:
- **Traveling Salesman Problem (TSP)**: Optimization using hill climbing and simulated annealing
- **Classification Problems**: Using decision trees, KNN, and SVM
- **Regression Problems**: Using linear and logistic regression
- **Path Finding**: Using BFS and DFS algorithms
